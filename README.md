# Bassir Technology — Corporate Website

> **See Further. Build Smarter.**

The official website for Bassir Technology — a modern, responsive, single-page corporate site built with vanilla HTML, CSS, and JavaScript.

## Slogan

**See Further. Build Smarter.**

Rooted in the meaning of "Bassir" (Arabic for *insightful* / *the one who sees clearly*), the slogan captures our promise: we bring foresight to every engagement and engineer solutions that outlast the moment.

## Site Overview

The site is a single-page experience with the following sections:

- **Hero** — Bold intro with slogan, mission, and animated statistics
- **Trust Bar** — Industry categories we serve
- **About** — The story behind the "Bassir" name and our approach
- **Solutions** — Twelve core service areas (see below)
- **Industries** — Vertical expertise (banking, healthcare, education, etc.)
- **Why Us** — Six differentiators
- **Process** — Five-step delivery timeline
- **Testimonial** — Featured client quote
- **CTA** — Conversion-focused call to action
- **Contact** — Full contact form and business details
- **Footer** — Site map and legal links

## Technical Details

- **Zero dependencies** — pure HTML, CSS, JavaScript
- **Fully responsive** — mobile-first design, works on all devices
- **Performance-first** — no build step required, deployable to any static host
- **Accessible** — semantic HTML, proper ARIA labels, keyboard-friendly
- **Modern effects** — CSS gradients, backdrop-filter, animated counters, intersection observers, subtle parallax

## Deployment

Deploy the entire folder to any static host:

- **GitHub Pages** — enable Pages in repo settings, point to this branch
- **Netlify / Vercel** — drag-and-drop or connect the repo
- **Custom domain** — point `www.bassir.net` to your host of choice

No build step needed.

## Local Preview

Open `index.html` directly in a browser, or serve locally:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
